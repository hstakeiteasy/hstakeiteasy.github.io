How to Play
Read this once, then jump in
  • 1Enter your name and Create Room. Share the Room Code with your friend via WhatsApp or Copy.
  • 2Your friend enters the code and taps Join Room. A 10-second countdown starts once both players are in.
  • 3You play 5 questions. Each question has 4 options. The first player to answer locks in their choice, and the next question appears for both.
  • 4Scoring: Correct = +10 points. Wrong = -5 points. Scores can go negative.
  • 5The whole match has a 5-minute time limit. If time runs out before question 5, the player with the highest score wins.
  • 6Highest score wins. Ties are possible. Press Play Again to start a new match.
Rooms automatically expire after 5 minutes if no opponent joins, and all match data is deleted from the database 1 hour after creation.
